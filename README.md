# BARNABE

Plateforme de gestion d’une entreprise de dépannage, développée avec PHP et MySQL.

- Application : `Base_de_donnée/`
- Rapport de réalisation : [rapport HTML](./rapport_plateforme_barnabe.html)
- Installation locale et import SQL : voir [le guide](./Base_de_donnée/README.md)

L’application PHP/MySQL doit être exécutée sur un hébergement compatible PHP et MySQL. GitHub Pages ne peut héberger que le rapport statique, pas exécuter l’application.
